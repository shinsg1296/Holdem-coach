# 친구와 온라인 대전 · Firebase 설정 (처음 한 번, 약 10분)

1. https://console.firebase.google.com 접속 → 구글 계정으로 로그인 → **프로젝트 추가** → 이름(예: holdem-bible) → 애널리틱스는 꺼도 됨 → 만들기
2. 왼쪽 메뉴 **빌드 → Authentication → 시작하기 → 로그인 방법 → 익명** → 사용 설정 → 저장
3. **빌드 → Realtime Database → 데이터베이스 만들기** → 위치: 싱가포르(asia-southeast1) → **잠금 모드로 시작** → 사용 설정
4. Realtime Database의 **규칙** 탭 → 내용을 이 폴더의 `database.rules.json`으로 바꾸고 **게시**
5. 프로젝트 개요 옆 톱니바퀴 → **프로젝트 설정 → 내 앱 → 웹(</>)** → 앱 이름 아무거나 → 등록
6. 화면에 나온 `firebaseConfig = { ... }` 부분을 복사해서 Claude 대화창에 붙여넣으면 앱에 넣어 드려요.
   (또는 앱의 "친구와" 탭에 직접 붙여넣어도 됩니다.)

무료(Spark) 요금제로 충분합니다. 동시 접속 100명, 저장 1GB까지 무료예요.
보안 규칙 덕분에 각자의 카드는 본인만 읽을 수 있고, 게임 상태는 방장만 바꿀 수 있어요.
